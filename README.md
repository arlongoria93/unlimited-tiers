# Unlimited Tiers

Solo 2D haste-ladder dungeon crawler. Instant max power. Gear makes you attack faster.

Play in a browser (phone or desktop). Built with [Phaser 3](https://phaser.io).

## Play

Open `index.html` from a local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080` or `http://YOUR_LAN_IP:8080` on your phone (same Wi-Fi).

To play on the public web: GitHub → Settings → Pages → Deploy from **main** / **root**.
The live URL will be:

https://arlongoria93.github.io/unlimited-tiers/

## Controls

- Drag / WASD to move
- Walk into a floor ring to pull a pack
- Packs do not chase across the room — run back to leash
- Green/gold door opens when the room is clear

## Loop

T1–T16 mall gates · weapon / armor / ring / trinket · one piece per boss · Fortune Desk shop · late tiers enrage

Progress saves in `localStorage` (`ut_phaser`).
